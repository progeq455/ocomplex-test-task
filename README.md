# 🤖 ИИ-Ассистент для менеджеров AmoCRM (Оффлайн-Прототип, с помощью Gemini). Тестовое задание для компании O-Complex

Интеллектуальный сервис-виджет для автоматизации работы отдела поддержки в диалоговом окне AmoCRM. Проект разработан на базе **React и TypeScript** и реализует концепцию **автономного семантического ИИ-движка (Offline AI Engine)**.

Сервис мгновенно анализирует контекст входящего сообщения клиента, сопоставляет его с корпоративной базой знаний и генерирует два независимых блока данных: **вежливый ответ клиенту** (готовый к копированию в один клик) и **подсказку по допродажам (апселлам)** для менеджера.

---

## 🚀 Технический стек и Архитектура

- **Фронтенд:** React 18+, TypeScript (строгая типизация ответов и семантических контекстов).
- **Сборщик:** Vite / Next.js (Client Component).
- **ИИ-Движок (Offline AI PRO):** Семантический анализатор контекста на базе регулярных выражений, весов фраз и триггерных карт состояний.
- **Преимущества архитектуры:**
  - **100% Автономность:** Не требует внешних API-ключей, токенов и бэкенда.
  - **Отказоустойчивость:** Защищен от сетевых сбоев, задержек API, проблем с CORS и блокировок SSL-сертификатов (актуально для распределенных систем).
  - **Идеальная скорость:** Скорость обработки запроса составляет менее 500 мс, что оптимально для демонстрации MVP.

## 🧠 Примеры сценариев для проверки (Тест-кейсы)

Движок поддерживает глубокий разбор как целевых, так и нестандартных / пограничных запросов. Введите следующие фразы в текстовое поле для проверки работы прототипа:

### 1. Тест на общий интерес к IT

- **Входная фраза:** `хочу по программированию что то взять` или `сколько стоит обучение`
- **Результат ИИ:** Движок определяет общий контекст, выводит прайс-лист на React/Node.js, а менеджеру предлагает квалифицирующий скрипт вопросов.

### 2. Тест на нецелевой заказ (Оффтоп)

- **Входная фраза:** `хочу оформить заказ на ремонт стиральной машины` или `мне сосиски и две пиццы с доставкой`
- **Результат ИИ:** Распознает попытку заказать сторонний товар. Генерирует вежливый отказ с напоминанием, что это IT-школа. Менеджеру выводится предупреждение: _«Допродажи запрещены. Закрыть сделку как нецелевую»_.

### 3. Тест на конкретный стек (React / Frontend)

- **Входная фраза:** `интересует курс по реакту с нуля` или `хочу на фронтенд`
- **Результат ИИ:** Выдает подробное описание программы React. Менеджеру активирует **триггер горячей допродажи**: предлагает сделать апселл продвинутого курса по Next.js со скидкой 20%.

### 4. Тест на конфликт / Возврат средств

- **Входная фраза:** `я передумал учиться верните деньги` или `сделайте мне возврат`
- **Результат ИИ:** Переключается в кризисный режим. Выводит правила возврата оферты (14 дней). Менеджеру блокирует продажи и предлагает скрипт удержания клиента (бесплатная заморозка, смена ментора).

## 🛠️ Как запустить и использовать проект

1. **Установка зависимостей:**
   ```bash
   npm install
   ```
2. **Запуск сервера разработки:**
   ```bash
   npm run dev
   ```
3. **Откройте приложение:** Перейдите по адресу `http://localhost:3000` (или `http://localhost:5173`).
4. **Тестирование:** Вставьте любую фразу из раздела «Тест-кейсы» в текстовое поле и нажмите кнопку **«Проверить обращение»**.

## 🔌 Перспективы интеграции в AmoCRM

Прототип полностью подготовлен к бесшовной интеграции в CRM-систему двумя способами:

1.  **Локальный виджет AmoCRM (JS SDK):** Рендеринг React-компонента во фрейме в правой панели карточки сделки (`lead`).
2.  **Chrome / Яндекс Расширение:** Использование встроенного в расширение скрипта `Content Script` (файл `content.js`), который автоматически считывает последнее сообщение из DOM-дерева активного чата AmoCRM по селекторам классов и передает его в интерфейс ассистента в один клик.
